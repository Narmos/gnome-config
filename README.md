# Ma configuration GNOME

Script d'automatisation pour personnaliser rapidement mon environnement de bureau **GNOME** via `gsettings`.

---

## 🚀 Usage

Ouvrez votre terminal dans le dossier du dépôt, autorisez l'exécution du script et lancez-le :
```bash
chmod +x config-gnome.sh
./config-gnome.sh
```

> [!IMPORTANT]
> N'exécutez pas le script avec les privilèges super-utilisateur via `su -` ou `sudo`, sinon cela impactera la session root au lieu de celle de l'utilisateur courant !
